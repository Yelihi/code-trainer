# Code Trainer 디자인 기준

## 글자

`frontend/src/typography.css`가 공통 크기·굵기·행간의 기준이다. 화면별로 임의의 px 크기를 추가하지 않고 역할에 맞는 토큰을 사용한다. rem 단위를 사용해 브라우저의 기본 글자 크기 설정을 따른다.

| 역할 | 토큰 | 기본 크기 | 굵기 / 행간 |
| --- | --- | --- | --- |
| 보조 정보·날짜·참고 자료 | `--text-caption` | 12px | 400 / 1.7 |
| 본문·입력·버튼 | `--text-body` | 14px | 본문 400, 버튼 500 / 1.7 |
| 개념 설명·학습 문장 | `--text-reading` | 16px | 400 / 1.85 |
| 카드·소제목 | `--text-subheading` | 20px | 600 / 1.4 |
| 섹션 제목 | `--text-section` | 24px | 600 / 1.4 |
| 페이지 제목 | `--text-page` | 32px | 700 / 1.4 |
| 첫 화면 대표 제목 | `--text-display` | 32–44px | 600 / 1.4 |
| 코드·편집기 | `--text-code` | 16px | 400 / 1.75 |

- 기본 크기는 브라우저 16px 설정 기준이다. 모바일에서도 본문·보조 글자·코드를 축소하지 않는다.
- 본문은 시스템 한글 글꼴, 코드는 `--font-mono`를 사용한다. 인라인 코드는 주변 문장 크기를 유지하고 배경·테두리로 구별한다.
- 중요 라벨은 본문 크기와 600 굵기를 사용한다. 보조 정보는 12px 아래로 내리지 않는다.
- 제목은 `--tracking-heading`, 보조 분류 라벨만 `--tracking-label`을 사용한다. 한글 설명에는 자간을 벌리지 않는다.
- SVG 텍스트도 같은 토큰을 사용한다. 도형과 함께 viewBox 비율로 확대·축소된다.

## 색상

기존 다크 팔레트를 유지한다. `--bg`는 페이지, `--panel`은 카드, `--line`은 경계, `--text`는 주요 글자, `--muted`는 보조 글자다. `--green`은 학습 상태·성공, `--purple`은 강조, `--error`는 실패에 사용한다. 코드 문법 색상은 일반 문장과 분리한다.

## 배치와 컴포넌트

- 긴 개념 문장은 최대 48em 안에서 읽도록 하고 제목·본문·참고 자료 순서로 위계를 유지한다.
- 메뉴·탭·버튼은 텍스트 크기에 맞게 높이가 늘어나거나 줄바꿈되도록 한다. 공간이 부족할 때 글자를 줄이지 않는다.
- 폼 입력은 14px, 라벨은 12px 이상을 사용한다. 도움말 모달과 접기/펼치기 본문에도 동일한 기준을 적용한다.
- 기본 입력·선택·버튼·라벨·상태 표시는 `frontend/src/components/ui`의 shadcn/ui 컴포넌트를 사용한다. 간단한 크기·간격·색상 조정은 Tailwind 유틸리티로 처리하고, 화면 구조와 복잡한 상태·반응형 규칙은 기존 CSS에서 조정한다.
- 제목·본문 크기는 공통 토큰에서 변경한다. Tailwind는 기존 CSS의 기본 스타일을 바꾸지 않도록 Preflight 없이 사용한다.

- 링크·메뉴·버튼에는 장식 화살표나 아이콘을 붙이지 않는다. 메뉴 열기·도움말·상태 표시 및 자료구조의 연결 방향처럼 기능이나 의미를 전달하는 경우만 사용한다.
- 서랍은 제목 영역을 고정하고 내용 영역의 높이만 애니메이션한다. 펼친 본문에는 별도 테두리를 중첩하지 않는다.
