# P15 Deep Inside — 명시적으로 켜는 예약 생성

설정 > AI 연결에서 예약 생성을 별도로 켜거나 끈다. 기본 꺼짐. 켜면 첫 확인은7일 뒤, 이후 주1회 서버가 켜져 있을 때 확인한다. 서버를 다시 켠 경우 밀린 주차를 몰아 실행하지 않고 한 번만 확인한다. 현재 유효한 선택 그래프 문맥이 마지막 시도와 달라졌을 때만 자동 생성한다. 수동 시도의 같은 문맥도 중복 자동 생성하지 않는다. 근거 부족/AI 미연결/진행 중이면 호출 없이 이유를 기록하고 다음 주에 확인한다.

자동 호출은 최근30일4회까지이며 호출당4000completiontokens는 P13설정 그대로다. 금액 상한 보장은 아니고 모델에 따라 비용이 달라진다. 시도 예약을 작업과 같은 즉시 트랜잭션에 저장해 중복 작업자/재시작/켜기 반복으로 한도를 우회하지 못한다. 실패·근거 변경·중단도 예약한1회를 소비한다. 사용자는 사용 횟수, 다음 확인일, 마지막 확인 이유를 볼 수 있다. 실패한 같은 문맥은 자동 재시도하지 않는다. 수동 생성은 기존 명시적 별도 동작이다.

끄면 아직 시작하지 않은 자동 작업을 중단한다. 이미 호출을 시작한 작업은 끝날 수 있음을 표시한다. 작업은 기존 한 owner/한 진행작업/claim/중단/근거 검증/현재 묶음 보존/개인 AI/usage 경로를 재사용한다. 스케줄 설정은 owner별 revision으로 동시 변경을 검출한다. 채택한 탐구는 예약 작업/정리 대상이 아니다.

만료된 현재 임시 묶음과 건너뛰기 fingerprint는 서버 정기 확인에서 정리한다. 작업 본문은 완료·실패·중단 때 제거한다. 중복 유료 호출을 막기 위한 최소 요청/작업 메타데이터는 유지한다.

주기·4회·30일 기본값은 앞서 빈 선택 응답에 대해 공개한 모델의 균형 기본값이며 사용자 확답으로 기록하지 않는다. 자동생성 기능 포함은 사용자 승인 범위이고 실제 활성화는 설정에서 명시적으로 한다.
