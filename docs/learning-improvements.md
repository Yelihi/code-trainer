# 학습·운영 개선 구현 계약과 검증

2026-10-06 사용자 승인 범위: 도움 사용 기록, 기존 문제 복습, 생성 문제의 테스트 보강, AI 사용량 기록, 운영 상태 화면. main 직접 push. 반례 찾기는 계획만 작성하고 뉴스레터는 적합성만 검토한다. 기존 미커밋 PLAN.md와 docs/deployment-design.md는 이번 변경에서 제외한다.

## 동작 계약

- 정답·힌트 조회는 계속 자유롭다. 앱이 반환한 도움을 `none/hint/solution`로 기록하고 제출과 같은 트랜잭션에 스냅샷을 남긴다. READ의 Run으로 출력이 공개된 경우도 풀이 참고다. 과거 제출은 `unknown`이며 독립 해결로 추정하지 않는다. 앱 밖에서 받은 도움은 알 수 없다.
- 기존 학습 정리는 최초 통과 제출을 근거로 유지하면서 당시 도움 기록을 포함한다. 나중에 정답을 열람해도 과거 제출 상태는 바뀌지 않는다.
- 복습은 별도 세션·초안·revision을 사용한다. 기존 코드·진도를 덮어쓰지 않는다. 첫 통과 다음 날부터 예정되며, 도움 없이 실패 없이 통과하면 3/7/14일, 실패하거나 도움을 사용하면 1일 뒤로 정한다. 같은 요청 재전송은 간격을 중복 변경하지 않는다. 진행 중 복습은 예정일과 무관하게 이어갈 수 있다.
- 복습은 기존 문제와 실행기를 재사용해 AI 비용이 없다. 새 세션은 시작 코드/빈 답안에서 시작한다. 삭제·제공 중단 문제는 목록에서 제외한다.
- 신규 AI 코드 문제에는 정상 실행되지만 지정 테스트에서 틀리는 대표 오답 1개를 요구한다. 기준 풀이 통과와 대표 오답 탈락을 모두 검증한다. 예외/시간초과로 실패하는 코드는 적절한 대표 오답으로 인정하지 않는다. READ와 기존 저장 문제의 계약은 유지한다. 이는 의미적 정확성 전체의 증명이 아니다.
- AI 호출별 모델·작업·생성 ID·수정 여부·입출력 토큰을 저장하고 사용자별로 조회한다. 응답에 usage가 없거나 네트워크 실패한 경우 미확인으로 표시한다. 원문·코드·키·응답 전문은 사용량 테이블에 저장하지 않는다. 과거 사용량을 추정하지 않으며 비용 상한이나 제공자 청구액을 보장하지 않는다.
- 운영 상태는 Mac의 5분 주기 별도 작업이 공개 인증서 만료일·SSD 여유·백업 성공 시각만 앱 데이터 볼륨에 전달한다. API에 Docker 제어 권한을 추가하지 않는다. 관리자만 볼 수 있으며 15분 이상 된 정보, 백업 36시간 초과, 내장 10GiB 미만, 인증서 14일 이내 만료를 안내한다.

## 검증 방법

프로젝트의 Python unittest, 프런트 타입/ESLint/API 테스트/빌드, 시작 검사, Worker 검사, Docker 격리 CI를 유지한다. 추가 동작 테스트는 backend/test_learning_features.py에 두고 CI 명령에 포함한다. 도움 스냅샷, 소유권, 기존 기록 호환, 복습 충돌·멱등성·삭제, 실패 후 재개, READ 출력 노출, 사용량 누락과 오류, 대표 오답의 실행 오류 거절, 운영 정보 누락·오래됨·권한을 검증한다.

브라우저 검증은 별도 SQLite의 합성 계정·문제로 진행한다. 운영 개인 자료를 테스트에 사용하거나 AI에 전송하지 않는다. 유료 AI 생성은 이번 검증에서 호출하지 않는다. 실제 생성 성공률과 추가 토큰 증가는 실사용 뒤 확인해야 한다.

frontend-system 기록용 MCP는 이 세션에서 제공되지 않아 도구의 계획/승인/체크 ID를 만들지 않았다. 실제 코드·검사 결과와 이 문서가 검증 근거다.

## 2026-10-06 로컬 확인 결과

- Python 전체 계약/배포 검사 61개 통과. 배포 전 제출의 재전송도 기존 결과를 반환하도록 호환성을 확인했다. 프런트 API 테스트 2개·타입·lint·빌드, 시작 절차 검사, Worker 테스트·Wrangler dry-run 통과. 기존 큰 프런트 번들 경고는 유지된다.
- 별도 DB의 브라우저에서 로그인, 복습 목록, 시작 코드/빈 답안, 힌트 조회, 저장, Submit, 완료 후 목록 이동과 다음 날 일정 표시를 확인했다. 제출 도움 표시와 완료 복습의 재제출 비활성화를 확인했다.
- 390px 화면에서 운영 상태와 AI 사용량 상세에 가로 넘침이 없었다. 사용량은 합성 제공자 응답, 운영 화면은 합성 스냅샷으로 검증했다.
- 실제 Mac 수집기를 터미널에서 실행해 앱/브로커 인증서 만료까지 89일, 내장 여유 44.33GiB, 마지막 백업 성공 시각을 앱 볼륨에 기록했다. 자동 LaunchAgent는 설치 후 macOS 외장 볼륨 접근 단계에서 대기해 사용자에게 허용을 요청했다. 터미널 성공을 자동 실행 성공으로 간주하지 않는다.
