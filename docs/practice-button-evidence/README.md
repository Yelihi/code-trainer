탭은 공통 버튼 radius에 덮이지 않는 직선 밑줄과 호버 여백을 사용한다. 저장 버튼은 링크용 padding:0 대신 최소 64px 폭과 사방 패딩을 갖는다. 상태는 Badge로 표시한다.

이탈 확인은 native dialog의 최상위 모달과 반투명 backdrop을 사용한다. 계속 작성/저장 후 이동은 두 동일 폭 열, 저장하지 않고 이동은 다음 줄의 전체 폭 텍스트 버튼이다. 초기 포커스·키보드 이동·Escape·계속 작성·저장 스피너·저장 중 취소 방지·실패 시 모달/본문 유지·재시도 후 이동·저장 없이 이동을 검사했다. PC와 390px 모바일에서 중앙 정렬과 가로 넘침 없음을 확인했다.

운영 배포는 하지 않았다.
