## 페이지별 결정

- **오늘의 학습:** 작은 바로가기를 제목 옆에 두고 이어하기를 가로로 압축한다. 왼쪽은 복습·진행 중인 학습, 오른쪽은 미해결 질문·AI 제안이다. 빈 상태도 목록의 밀도를 과도하게 늘리지 않는다.
- **자료와 해석 목록:** 입력 방법과 검색·필터를 작은 도구 영역으로 모은다. 긴 제목과 본문 미리보기를 세로 목록으로 훑는다.
- **자료 상세와 해석:** 버전/목차, 읽기 본문, 해석 시작/해석 당시 원문으로 나눈다. 과거 버전을 선택하면 중앙 본문과 해석 대상 버전이 일치한다. 당시 URL과 최신 본문 복귀를 유지한다.
- **레퍼런스:** 목록은 제목·내 설명·작성 시점을 중심으로 한다. 상세는 사용자 설명·AI 설명을 본문에, 연결한 근거·Skill·변경 이력을 보조 영역에 둔다.
- **실습:** 사전 생성 문제집 / 자료기반 코드 실습의 두 진입만 둔다. 기존 수동 문제집·React/Vue·실습 질문지 생성은 제거한다.
- **질문·복습:** 검색/필터와 목록을 분리하고, 질문 계층과 상태를 보존한다. 복습 탭은 한 패널씩 보여주며 지금 수행할 행동을 명시한다.
- **공통:** 읽는 본문은 충분한 글자 크기와 행간을 사용한다. 좁은 화면에서는 세로로 쌓고, 원문/본문 바로가기로 긴 페이지를 이동한다. 키보드 초점·오류 재시도·불러오는 상태를 보존한다.

구현과 화면 검증 결과는 `docs/technical-learning-evidence/2026-11-16-uibowl/`에 기록한다. 이 문서는 다음 작업에서 다시 사용할 참고 기록이며, 운영 배포를 의미하지 않는다.


## 2026-11-16 화면 피드백 후 결정

이 항목은 위의 이전 도메인 구성보다 우선한다. 자료는 원자료/실습으로 줄이고 개념 지도와 기존 노트 관리 메뉴를 제거한다. 질문은 읽기 우선이며 질문·설명·참고 자료만 표시하고 수정 버튼으로 입력한다. 레퍼런스의 질문 가져오기는 레퍼런스 서비스에서 수행한다.

추가 Mobbin 검색은 유료 플랜 필요 응답으로 실패했으며 결과 이미지를 확보하지 못했다. 유아이볼도 같은 날 무료 한도에 도달했다. 아래는 별도로 확인한 서비스 공식 문서이며 Mobbin 검색 결과가 아니다.

- [토스 ListRow](https://tossmini-docs.toss.im/tds-mobile/components/ListRow/list-row-overview/): 왼쪽/중앙/오른쪽 영역을 구분한 목록 구성. 질문 목록은 이를 참고해 상태·제목/수정일·이동 표시로 설계했다. 구체적인 수치와 색상은 Code Trainer의 결정이다.
- [토스 Button](https://tossmini-docs.toss.im/tds-mobile/components/button/): loading 스피너와 접근성 이름. 공통 Button.loading으로 적용했다.
- [Linear Display options](https://linear.app/docs/display-options): 이슈 목록에 필요한 속성을 선택해 보여주는 구성. 질문은 제목과 상태·시점만 먼저 보이고 실제 저장값은 상세에서 읽는 방향으로 적용했다. Linear 화면을 픽셀 복제한 것은 아니다.

입력창 내부에만 1px 포커스를 표시한다. 상위 form/main의 반응과 광택 효과는 제거한다. 기본 필드 간격 24px, 레이블 간격 8px, 안내/글자 수 12px, 푸터 간격 12px를 따른다. 빈 상태는 아이콘·짧은 제목과 필요한 동작 하나를 우선하며 기본 설명 문단을 추가하지 않는다. 작성 화면은 64dvh 이상의 본문과 접힌 출처 입력을 사용한다.

삭제한 수동 문제집·질문지의 과거 방문 기록은 오늘의 학습 이어하기와 AI 추천 후보에서 제외한다. 과거 DB와 실습 기록은 유지한다.
