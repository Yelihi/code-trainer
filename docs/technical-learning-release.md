# 기술 학습 중심 전환과 검증

기준 main: `e679612`. 대표 브랜치: `feat/technical-learning-redesign`. GitHub Issue를 생성하지 않고 PLAN.md의 01~14 순서로 같은 브랜치에서 구현했다. 원래 체크아웃의 사용자 변경은 수정하지 않았다.

## 사용자 전환

주요 메뉴는 오늘의 학습·자료·레퍼런스다. 자료 영역의 원자료·문제집·개념 과정·실습 메뉴는 항상 표시하며, 오늘의 학습에서도 문제집을 바로 연다. 기존 자료·노트·문제집·풀이·복습 URL은 유지한다. 위키 `/project-brain/*`와 개인 탐구 `/apply/*`는 새 흐름과 내보내기 안내를 제공한다.

범용 위키, 개인 기록 초안, Deep Inside의 유료 생성 API는 410을 반환한다. 일일 AI 질문 API도 생성하지 않고 새 홈을 안내한다. `insight_schedule.poll`을 앱 lifespan에서 시작하지 않는다. 기존 예약 설정 행을 삭제하거나 학습 상태로 변환하지 않는다. RSS 수집과 배포/모니터/백업 작업은 유지한다.

기존 위키·개인 기록·온톨로지 테이블은 삭제하지 않았다. 공유 원자료와 버전 내보내기, 이전 참조 검증을 위해 backend의 기록 읽기·수동 저장 호환 API와 archive 엔진을 남겼다. 새 UI에서는 진입하지 않는다. 이 코드는 개인 데이터의 별도 이전이 합의되고 전체 이력 내보내기/복원 검증이 유지될 때 제거할 수 있다. archive 엔진 회귀 테스트는 직접 모듈을 검사하고, 종료된 HTTP 유료 생성이 다시 열리지 않는 검사와 구분한다.

## 데이터 계약

- 질문은 기존 트리/상태/revision을 보존하면서 targets와 origin을 추가했다. 원래 질문을 해결 상태로 추정하지 않는다. 추천의 숨김·미루기는 study_choices에 별도 저장한다.
- 학습 위치 기록은 방문 위치이며 읽음/이해/숙달의 증명이 아니다. 기존 풀이와 복습 초안을 새 구조로 복제하지 않는다.
- 레퍼런스는 사용자 글의 불변 버전과 별도 AI 작업 이력을 갖는다. 주제 중복/다른 탭 충돌/응답 유실 재전송을 검사한다. AI 생성 중 사용자 글이 바뀌어도 덮어쓰지 않는다.
- 연결한 자료의 버전·본문 digest와 제출/도움 기록을 보관한다. 자료 저장, 질문, AI 설명, 사용자 설명, 실제 제출 기록을 구분한다. 비공개 정답과 기초 문제의 비공개 해설은 AI 근거로 가져오지 않는다.
- Skill은 명세의 필수 name/description YAML 헤더와 Markdown 지침을 생성한다. 소문자 이름/길이, 내부 패키지 링크를 검증한다. ZIP에는 references/REFERENCE.md 및 provenance.json을 포함한다. 검증 표시는 형식·연결 검사이며 생성 예제를 실행했다는 뜻이 아니다.

## 배포와 롤백 준비

1. 브랜치 CI, 위 테스트 결과와 UI 검토 결과를 확인한다. 기존 백업은 [보존·복구 안내](technical-learning-preservation.md)에 따라 새 파일로 만든다.
2. 배포 시 사용자 입력 저장을 안내하고 main에 검증된 변경을 병합한다. 기존 배포 파이프라인을 따른다. 이 문서는 병합/배포를 실행한 기록이 아니다.
3. 새 DB 테이블·열은 추가 방식이며 기존 개인 기록을 삭제하지 않는다. API와 정적 프런트엔드를 같은 릴리스로 배포한다. 코드 편집용 폰트 등 정적 assets도 함께 제공한다.
4. 배포 완료 상태/컴포넌트 SHA와 health, 실제 학습 재개·질문 저장·레퍼런스 읽기·다운로드를 다시 확인한다. 이전 위키 생성과 자동 insight 예약이 실행되지 않는지 확인한다.
5. 롤백은 배포된 코드 커밋을 되돌리는 방식을 우선한다. 새 테이블은 보존한다. 이전 DB 백업으로 교체하면 배포 이후 기록이 빠지므로 자동으로 되돌리지 않는다. DB 복구가 필요하면 현 DB를 먼저 별도 보관하고 신규 기록 보존 범위를 확인한다.

원래 운영 설정과 설치된 배포 스크립트는 수정하지 않았다. 새 LLM Wiki 서비스나 실제 데이터 이전, 자동 Skill 설치/공개도 수행하지 않았다.
