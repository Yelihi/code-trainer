# 프로젝트 브레인 구현 목록

Code Trainer 앱에서 프로젝트 경험을 원자료와 함께 저장하고 연결 그래프에서 탐색한다. 앱의 기존 학습 개념 그래프와 데이터는 유지한다.

- [x] 원자료를 기존 보관 자료의 특정 버전, 직접 발췌, 선택한 GitHub PR에서 등록한다.
- [x] 관찰·결정·교훈을 문장별 근거와 구분해 저장하고, 수정 버전·검토 상태·보관·대체 관계를 관리한다.
- [x] 선택한 원자료로만 명시적 AI 초안을 만들고, 실패·중단·중복 요청을 처리한다.
- [x] 기록 목록·검색·작성·상세·근거 확인 화면을 제공한다.
- [x] 원자료·기록 노드와 근거·연관·반박·대체 관계를 그래프 및 관계 목록에서 탐색한다.
- [x] 선택한 기록을 출처·관계와 함께 Markdown으로 내보낸다.
- [x] 소유권, 원본 버전, 인용 검증, AI 재시도, 그래프 연결, 내보내기 및 프론트엔드 검증을 완료한다.

사용 방법과 범위: [프로젝트 브레인 사용 안내](project-brain.md)
