사용자가 이전 명조/먹색·금색 테마를 거절한 뒤 구현한 별도 디자인이다. 이전 `2026-11-15-redesign` 폴더의 화면과 검토 결과는 이전 버전의 이력이다.

사용자 지정 색상은 `#49144F`, `#E86FB5`, `#E2E2E2`, `#181818`이며, 폰트는 원래 Code Trainer의 플랫폼 산세리프를 사용한다. 첨부 이미지는 모바일 구성과 팔레트 참고이며 픽셀 복제 시안이 아니다. 이미지 시안 승인이나 과거 검토의 새 디자인 승인을 주장하지 않는다.

## 캡처 출처와 범위

Firefox의 실제 Vite production build를 native 브라우저로 열고 반응형 뷰포트의 카메라로 PNG를 저장했다. 이미지 생성·합성·후처리는 하지 않았다. 격리된 임시 DB의 예시 자료이며 사용자 개인 자료를 포함하지 않는다. AI 설명과 Skill은 합성 fixture로, 실제 유료 생성 품질을 보여주는 증거가 아니다.

| 파일 | CSS 뷰포트 | PNG 픽셀 |
| --- | --- | --- |
| today-desktop / library-desktop / problem-books-desktop / references-desktop | 1440×1000 | 2880×2000 |
| today-mobile / library-mobile / problem-books-mobile / references-mobile / reference-detail-mobile / practice-mobile | 390×844 | 780×1688 |
| question-short-mobile | 390×500 | 780×1000 |

모두 DPR 2의 첫 뷰포트 캡처이며 전체 문서 캡처가 아니다. 하단 탐색은 고정되어 있고 콘텐츠에는 스크롤 끝 여백을 둔다. 실제 모바일 OS 키보드는 검사하지 않았다. 질문 캡처의 한글은 붙여넣은 초안이며 native IME 조합의 검증 증거로 해석하지 않는다.

실제 메뉴 클릭으로 자료→문제집을 열었다. 문제집 메뉴가 접힌 상세에 숨지 않고 모든 자료 화면에 나타나며, 오늘의 학습에도 문제집 바로가기가 있다. 질문창을 좁힌 화면에서 입력·연결·저장·닫기를 확인했고, 닫은 뒤 기존 풀이의 예측 초안이 유지되었다. 실제 저장·실행 동작을 이번 디자인 검사에서 새로 제출한 것은 아니다.

자동 검사: frontend 테스트 31개, TypeScript, ESLint, Vite build 통과. 메뉴 활성 상태와 자료 영역에서 문제집 접근이 접히지 않는 계약을 포함한다. 디자인 detector는 이전 DESIGN.md를 제외하고 새 주요 소스/테마에 한 번 실행해 `[]`를 반환했다. 기존 번들 크기 경고는 유지된다.

독립 전체 검토는 11개 캡처와 지정 소스를 확인하고 중복 안내 문구 1곳을 지적했다. 문구와 불필요한 아이콘/스타일을 제거하고 Today 두 화면을 재촬영한 뒤 같은 검토자의 수정 판정에서 `disposition: ship`을 받았다. 이 판정은 해당 수정과 회귀 범위이며, 전체 흐름의 추가 실기기 검증을 의미하지 않는다. [검토와 판정](REVIEW.md)을 함께 보존한다.
