# P14 Deep Inside — 채택한 탐구와 내 기록

현재 제안에서 사용자가 채택하면 질문·가이드·당시 근거·모델을 독립된 탐구 기록으로 보존한다. 현재 임시 묶음 교체/만료가 채택 기록에 영향을 주지 않는다. 동일 묶음/항목 재전송은 같은 기록이다. 다른 owner 또는 교체/만료/근거 변경된 묶음은 새로 채택할 수 없고 기존 채택은 당시 근거와 변경 경고를 유지한다.

응용하기에 ‘나의 탐구’ 목록/상세를 추가한다. 사용자가 예상·실습 관찰·질문을 자유롭게 작성하고 명시적으로 저장한다. 낙관적 revision으로 다른 창의 수정을 덮어쓰지 않으며 실패 시 입력을 유지한다. 읽기/저장만으로 그래프 등록이나 숙달·복습 판정을 하지 않는다. 작성자 분리: AI 제안과 내 기록을 별도 표시한다. 본문이 동일한 저장은 revision을 늘리지 않는다.

건너뛰기는 원문 제안 본문을 영구 보존하지 않고, 개념·관계 조합의 fingerprint만30일 유지한다. 현재 묶음에서 숨기며 같은 연결의 새 제안은30일간 제외한다. 채택과 건너뛰기는 명시적 동작이고 서로 반대 동작으로 바꿀 수 없다. 예약 생성은 P15에서 별도 구현한다.

검증: owner/묶음/항목/만료/근거 가드, 채택 중복 및 영속성, 건너뛰기 TTL/재생성제외, 저장충돌·본문동일, 프론트 라우트·저장실패 입력보존·모바일. 실제provider/운영DB 없음. release만 병합.
