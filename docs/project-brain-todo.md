# 세컨드 브레인 · LLM Wiki 구현 범위

- [x] 기존 원자료 스냅샷, 프로젝트 기록과 학습 그래프를 보존한다.
- [x] 보관 자료·원자료·PR을 선택하고 수정·보완한 사용자 문서를 별도로 저장한다.
- [x] 사용자 문서의 버전과 원자료·과거 위키 답변 출처를 보존한다.
- [x] 명시적으로 선택한 문서 버전과 기존 위키를 읽고 주제 페이지를 누적 갱신하는 AI 변경안을 생성한다.
- [x] 변경 전후·인용·페이지 연결을 검토하고 제목·요약·본문을 편집한 뒤 원자적으로 반영한다.
- [x] 중복 요청, 소유권, 인용·연결 유효성, 문서·위키 충돌, 실패·재시작 상태를 검사한다.
- [x] 위키 페이지를 근거로 질문에 답하고, 유용한 답변을 사용자 문서로 보완해 재반영한다.
- [x] 오래된 문서 인용·연결 상태와 AI의 충돌·공백 점검을 제공한다.
- [x] 위키 목차, 페이지·문서 이력, 역방향 연결, 활동 이력과 Markdown ZIP을 제공한다.
