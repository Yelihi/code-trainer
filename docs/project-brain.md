# 프로젝트 브레인 사용 안내

Code Trainer의 **데이터 쌓기 → 프로젝트 브레인**에서 프로젝트 판단과 경험을 원자료에 연결해 보관합니다. 기존 개념 학습 그래프와는 별도입니다. 자동 수집이나 자동 기록은 하지 않습니다.

## 기록 흐름

1. **원자료 추가**에서 직접 발췌를 붙여 넣거나, 자료 보관함의 본문 버전 또는 GitHub PR 주소를 선택합니다. 저장 시점의 본문을 별도 스냅샷으로 보존합니다. GitHub PR은 설정에서 연결한 계정으로 제목과 본문을 가져옵니다.
2. **직접 기록**으로 관찰·결정·조건부 교훈을 쓰거나, 원자료를 1~5개 선택해 **AI로 정리**를 요청합니다. AI 결과는 초안이며 저장 전 편집합니다. 초안만 생성해도 프로젝트 기록이 자동으로 늘어나지는 않습니다.
3. 관찰과 사용자 진술에는 원자료를 선택하고 **원문에 실제로 있는 문구**를 인용합니다. AI 추론은 별도로 표시합니다. 서버가 인용 문구와 저장된 원문을 다시 대조합니다.
4. 기록 상세에서 내용과 근거를 확인한 뒤 **이 버전 확인**을 누를 수 있습니다. 수정하면 새 버전이 남고 확인 상태는 미확인으로 돌아갑니다. 오래된 판단은 보관하거나 새 기록에서 **대체** 관계를 연결합니다.
5. **연결 그래프**에서 원자료, 기록, 근거·연관·도출·반박·대체 관계를 선택해 탐색합니다. 그래프 아래 관계 목록으로도 같은 연결을 확인할 수 있습니다.
6. 기록 상세의 **Markdown 내보내기**에는 현재 기록, 인용, 연결 관계, 사용한 원자료 스냅샷이 포함됩니다.

## 저장 범위와 주의

- 자료와 기록은 현재 로그인한 사용자에게만 보입니다. 프로젝트 구분값은 현재 Code Trainer 하나입니다.
- 직접 발췌의 출처와 진실성은 사용자가 확인합니다. 인용 검증은 스냅샷에 문구가 실제로 있는지만 검사합니다.
- AI 초안이 실패하거나 서버 재시작으로 중단되면 원자료는 유지됩니다. 실패한 요청 ID를 다시 보내면 같은 결과를 돌려주며, 새 시도는 새 요청 ID로 시작합니다.
- 현재 목록은 최근 수정한 기록 200개까지 보여줍니다. 대량의 기록을 다루는 검색·그래프 최적화는 이 첫 버전의 범위에 포함하지 않았습니다.
