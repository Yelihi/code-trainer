# P13 Deep Inside — 근거가 있는 현재 제안 묶음

사용자가 응용하기에서 명시적으로 생성한다. 개인 AI 설정을 매 호출에 적용하고 한 번의 구조화 호출로 최대3개 가이드를 만든다. 등록된 개념과 관계가 부족하면 호출 없이 이유와 그래프 진입 링크를 표시한다. 자동 생성·채택 저장은 다음 P14/P15 흐름이다.

기존 SQLite 온톨로지에서 active이고 질문이 아닌 근거가 있는 관계와 양끝 개념을 제한해서 읽는다. 반박 근거가 있는 관계는 확정 연결로 사용하지 않는다. 최근 근거의 한 개념을 중심으로 한 단계 이웃을 선택하고, 최대12개 개념·6개 관계·8개 출처·32개 짧은 인용(각1000자)을 보낸다. 원문 전체·코드 정답·키를 포함하지 않는다. AI 해석·내 작성·원문 근거를 구분하고, 제한된 일부 그래프만 사용했음을 표시한다.

각 제안은 연결 이유, 스스로 답할 질문, 찾아볼 근거와 읽기 안내, 작은 실습 가이드, 남길 결과물, 확정 관계/검증할 가설 구분을 갖는다. 모델이 반환한 개념·관계·근거 ID가 전부 해당 요청의 owner/문맥에 있는지, 관계 양끝이 제안 개념인지, 해당 관계 근거를 실제 인용했는지 검증한다. 완성된 답/코드를 담는 필드는 없고 코드블록도 거부한다. 인용된 출처 버전·작성 주체와 그래프/원본 링크를 표시한다. 그래프 자동 등록·숙달 판정은 없다.

owner별 진행 작업은 하나다. 요청 ID 재전송은 같은 작업이며 중복 작업자가 같은 요청을 호출하지 않는다. 작업은 queued/running/ready/failed/stale/interrupted. 시작 전과 응답 후 저장 트랜잭션에서 근거 상태를 검사한다. 실패·중단·근거 변경이면 기존 현재 묶음을 덮어쓰지 않는다. 실제 사용 모델은 usage의 호출 정보로 갱신한다. 재시작 시 진행 작업은 interrupted로만 표시하고 자동 유료 재시도하지 않는다.

미채택 본문은 현재 묶음만30일 임시 보관하고 교체/만료 시 제거한다. 작업의 입력 스냅샷은 종료하면 제거하며 작업 메타데이터만 남긴다. 원문이 변경·보관됐으면 기존 묶음도 오래된 근거임을 표시한다. 이30일과 호출당4000 completion token 초기값은 사용자 선택 응답이 비어 호스트 지시에 따라 공개한 균형 기본값이며 사용자 확답으로 기록하지 않는다. 자동 생성은 아직 없고 이후에도 기본 꺼짐이다. 토큰 한도는 금액 보장이 아니다.

검증: 빈/반박/구버전 그래프 호출0,owner/ID/인용/범위 가드,한 작업/재전송/동시claim,생성 중 근거 변경과 재시작 늦은 결과,실패 시 기존 묶음 유지,교체/만료 입력본문 정리,실제 mocktransport 개인모델/토큰상한/usage,기존AI 회귀. 실제 브라우저 생성→대기→가이드·출처,실패/재시도,새로고침/모바일. 운영 키·실AI 없음. Release만 병합.
