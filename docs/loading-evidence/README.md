# 로딩 상태 정리 · 2026-11-20

UI Bowl 로딩 패턴을 확인해 기존 테마 안에서 적용했습니다.

- [스티키](https://uibowl.io/name/%EC%8A%A4%ED%8B%B0%ED%82%A4?patterns=%EA%B2%80%EC%83%89&imgId=cmv3b8s9q00ahjv06vl7t3z2z): 작은 회전 표시와 짧은 조회 안내.
- [무디](https://uibowl.io/name/%EB%AC%B4%EB%94%94%20Moodee?patterns=%EC%A1%B0%ED%9A%8C%ED%95%98%EA%B8%B0&imgId=cmsda1x4w000fjm04wai37n4c): 분석 진행 상태의 시각적 구분.

## 적용

첫 조회는 콘텐츠 형태의 중립색 스켈레톤, 백그라운드 작업은 공통 회전 표시·상태 배지·제목으로 구분합니다. 해석, Skill, 기술 설명, 학습 과정/문제 생성, 학습 추천, 원문 수집/갱신, 코드 실행, 정답 조회, 개념 검색, 검토 질문에 적용했습니다. 기존 결과가 있으면 그대로 유지하고 작은 진행 표시를 사용합니다. 버튼 요청은 기존 중앙 스피너를 재사용합니다.

새 라이브러리를 추가하지 않고 기존 Lucide와 CSS를 사용합니다. 실제 서버 상태와 단계만 표시하며 진행률이나 완료 예상 시간은 만들지 않습니다. 모션 감소 환경에서는 회전·스켈레톤 애니메이션을 중지합니다. 원문 수집의 수동 상태 확인, 오류 복구, 파일 초안·실행 기록은 유지합니다.

## 확인

`check.mjs`는 API fixture를 사용하며 유료 AI나 사용자 데이터를 변경하지 않습니다.

- 해석 queued/running × 1440/768/390, 가로 넘침과 카드 높이
- 재생성 중 이전 문서 유지, 완료 시 로딩 제거
- 모션 감소, 첫 조회 스켈레톤, 브라우저 오류 없음
- 기존 홈/설정 18개 화면과 10개 상호작용, Skill 9개 반응형 화면과 수명주기/편집, 원문 복구 15개 화면과 저장/초안/재시도, 실습 버튼/이탈 팝업 회귀 확인
- 프런트엔드 테스트 33개, lint, production build 통과. 기존 번들 크기 경고 유지.

스크린샷의 자료와 작업 상태는 검증용 데이터입니다. 실제 AI 완료 소요 시간은 검증하지 않았으며 배포 전 로컬 변경입니다.
