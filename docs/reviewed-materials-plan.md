# P8 검토한 버전을 추출 가능 자료로

사용자가 채택한 D2a를 구현한다. 완료된 AI 해석에서 ‘이 버전 정리 확인’, 저장한 내 답변·요약에서 ‘이 버전 검토 완료’를 누르면 추출 가능 목록에 해당 버전 하나가 나타난다. AI 생성 성공, 편집, 열람만으로 확인 처리하지 않는다. 이 동작은 AI 호출·그래프 등록·복습 일정 생성과 별개다. 직접 노트의 기존 수동 지식 등록 경로를 유지한다.

확인 대상은 종류(해석/사용자 실습 기록), ID, 버전이다. 해석은 변경 불가능한 결과 ID와 원문 버전을, 실습은 질문지 ID와 사용자 작성분 버전을 사용한다. 원문/작성분의 현재 버전과 다르거나 원문이 보관되었으면 변경됨/보관됨으로 표시하고 새 확인·후속 추출은 차단한다. 과거 확인 이력과 본문은 지우거나 최신본으로 바꾸지 않는다. 같은 버전 재전송/동시 확인은 같은 기록을 반환한다. 다른 사용자의 자료나 비어 있는 학습 기록은 확인할 수 없다.

새 자료 읽기 함수는 기존 해석·질문지·사용자 작성분과 원문 조회를 조합한다. 작성 주체와 원문 연결을 보존하며 별도 원문 사본이나 범용 이벤트 버스를 만들지 않는다. 추출 가능 목록은 페이지별로 확인 기록과 현재 자료 상태를 조합한다. 상세에서 확인한 정확한 본문을 읽고 원래 화면으로 돌아갈 수 있다. AI 추출·수정·등록은 다음 P9/P10에서 같은 상세에 연결한다.

프론트엔드는 기존 api/useResource/Markdown과 목록·카드 스타일을 재사용한다. 실습의 미저장 변경/저장 처리/충돌이 있으면 확인 버튼을 비활성화해 보이는 초안을 저장된 버전으로 오인하지 않게 한다. 확인 실패는 편집기 초안을 건드리지 않는다. 사용자·자료·버전이 바뀌면 확인 UI의 상태도 분리한다.

변경: backend/materials.py, material_schema.py, test_materials.py, db.py, api.py; frontend/MaterialReview.tsx, KnowledgeCandidates.tsx, Interpretations.tsx, PracticeRecords.tsx, Navigation.tsx/Navigation.test.ts, main.tsx; CI 테스트 목록.

검증: 명시 확인 전후 목록/AI0회/그래프·일정0건, 중복·동시 확인, 소유권·미완료·빈 내용 거부, 본문 저장과 확인 경합, 원문/작성분 변경 후 stale 및 보관 상태, 정확한 과거 본문 보존, 해석/실습 양쪽 실제 브라우저 진입·미저장 버튼 차단·오류·모바일. 기존 답변 저장/해석 회귀와 프론트엔드 필수 검사 유지.
